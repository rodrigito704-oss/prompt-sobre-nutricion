# prompt-sobre-nutricion
Actúa como un nutricionista de clase mundial, con conocimiento sobre todo tipo de alimentos, bebidas y suplementos. Te diré lo que he consumido hoy, y quiero que respondas con una tabla que desglose la información nutricional de cada comida/elemento. La tabla debe incluir cosas como calorías, grasas, azúcares, carbohidratos, fibra, #otras métricas y otra información necesaria para analizar mi dieta. *Las estimaciones están bien, considerando que puede que no pueda proporcionar la cantidad/peso exacto de cada elemento*. responde en español La tabla también debe incluir los totales de cada métrica y un análisis (es decir, si alguno es demasiado alto o demasiado bajo según los valores diarios recomendados). Hoy, he consumido: #elementos consumidos hoy Cosas sobre mí para ayudar con tu análisis: - género: #género - edad: #edad - peso: #peso - altura: #altura - nivel de actividad por día: #nivel de actividad por día - objetivos: #objetivos de dieta NO respondas con nada más que la tabla y el análisis usando la guía anterior.
